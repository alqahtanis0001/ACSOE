## 7. What went wrong today, and what was learned

- **The build estimate ran about 5 h over.** The lead's 12–17 h figure was a sum of parts, not a
  measurement. The run-cost estimate was wrong by 3× until a-replay measured it (D16). Lesson: say
  "estimate" and measure before promising a time.
- **A partial edit failed on CRLF.** A multi-file edit script asserted each anchor, wrote two files,
  then failed on a third that was CRLF in the working tree. Re-running the whole script would have
  duplicated the two appended log entries. Caught by counting the entries (1 each) and re-running only
  the failed part after normalising line endings. Afterwards a grep for the old wording found one
  missed line (the task list's acceptance column). Lesson: normalise line endings **before** an
  anchored edit, and grep for the old wording after every multi-file edit.
- **Heredocs:** a bash heredoc carrying backticks ran them as commands and silently deleted words from
  a comment, and another heredoc failed to parse. Lesson (already a memory rule): write scripts with
  the file tool and run them; never put escapes or backticks in a heredoc.
- **Red gates on mutation anchors (b4, b5, b6):** new code that copies an existing idiom makes
  criterion-test anchors ambiguous or missing. Team rule adopted: run all of `tests/verify` before any
  DONE.
- **A gate that never ran reported success:** argument overflow (exit 126) in a wrapper whose last
  command succeeded. Lesson: confirm a launch by its evidence (a log's first lines, a live PID),
  never by the return code.
